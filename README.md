# E-Commerce Transactional Data Analysis


## Project Overview

This project delivers a comprehensive, data-driven analysis of 2 years of e-commerce transactional data spanning 8 product categories and 25 distinct cities. By leveraging Python's data science ecosystem, the project uncovers critical business trends across sales performance, profitability, customer behavior, and regional operations to support strategic decision-making.

## Key Insights & Features

• Exploratory Data Analysis (EDA): Detailed evaluation of core business metrics including sales volumes, costs, profit margins, and discount structures.
• Operational Performance: Deep dive into delivery logistics, product return rates, and customer satisfaction ratings.
• Customer Segmentation: Behavioral profiling to identify high-value customer clusters and purchasing patterns.
• Interactive Visualizations: High-impact statistical plots and dynamic dashboards designed to communicate complex data trends clearly to stakeholders.

## Tech Stack

• Language: Python
• Data Processing: Pandas, NumPy
• Data Visualization: Matplotlib, Seaborn, Plotly
• Analysis Techniques: Statistical Analysis, Data Preprocessing & Cleaning, Cohort Analysis / Segmentation
